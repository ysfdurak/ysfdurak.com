# ysfdurak.com

Kişisel portföy sitesi: operasyon, veri ve karar destek projeleri. Türkçe (`/tr/`) ve İngilizce (`/en/`).

- **Teknoloji:** [Astro](https://astro.build) (statik site), Cloudflare Workers (statik dosya yayını)
- **Yayın:** `main` dalına her push → Cloudflare otomatik derler ve yayınlar
- **Yerelde çalıştırma:** `npm install` → `npm run dev` → http://localhost:4321/tr/

Ayrıntılar: [docs/NASIL-CALISIR.md](docs/NASIL-CALISIR.md)
